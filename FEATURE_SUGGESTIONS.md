# Feature Suggestions for Logotham

## 1. Smart Text-to-Logo Generator (High Priority)
*   **Goal:** Allow users to generate logo concepts from a text description.
*   **Implementation:** Client-side keyword mapping (deterministic).
*   **Status:** Planned in `SMART_GENERATOR_PLAN.md`.

## 2. Advanced Text Styling
*   **Goal:** Provide professional typography controls.
*   **Features:**
    *   **Letter Spacing:** Control tracking between characters.
    *   **Line Height:** Control leading for multi-line text.
    *   **Text Outline:** Add stroke/border to text characters.
    *   **Curved Text:** Allow text to follow a circular path (arc).

## 3. Shape Primitives
*   **Goal:** Allow composition with basic geometry.
*   **Features:** Add a "Shapes" library with editable geometric primitives (Circle, Rect, Triangle, Star, Line) that can be colored and layered like icons.

## 4. Background Patterns & Textures
*   **Goal:** Add depth and character to logo backgrounds.
*   **Features:**
    *   **Noise/Grain:** A slider to add noise texture.
    *   **Patterns:** CSS-based patterns (dots, grid, lines).
    *   **Image Upload:** Allow user to upload a background image.

## 5. Cloud Persistence & Auth
*   **Goal:** Enable cross-device usage and permanent storage.
*   **Features:**
    *   User authentication (Supabase/Firebase/NextAuth).
    *   Database storage for user projects.

## 6. Print-Ready Support
*   **Goal:** Professional output formats.
*   **Features:**
    *   PDF Export.
    *   CMYK Color Preview/Conversion (simulated).
